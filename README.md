# 32-bit-RISC-style-Pipelined-Datapath-Verilog-upgrade

Implemented a 16‑bit RISC datapath, then extended the same pipeline to 32‑bit with a shared register file, forwarding logic, and a self‑checking testbench; designed a 5‑stage in‑order pipeline (Fetch, Decode, Execute, Memory, Writeback) and wrote a Verilog testbench that automatically checks final register values and reports TEST PASSED / TEST FAILED
